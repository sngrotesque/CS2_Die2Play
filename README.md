# CS2_Die2Play
游玩CS2时，被击杀即跳转的程序；使用Flutter框架开发，Windows平台。

教程视频：[我制作了一个CS2被击杀都刷抖音的程序](https://www.bilibili.com/videos/?)

## 手动构建

```bash
git clone git@github.com:sngrotesque/CS2_Die2Play.git

cd CS2_Die2Play

flutter pub get
flutter build windows --release
```
